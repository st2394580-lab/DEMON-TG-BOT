# 🤖 DEMON-TG-BOT

A modular Telegram bot built with Node.js and Telegraf.

## Features

- Auto reply
- Start / Help / Menu
- Ping / Alive / Info
- User ID
- Group information
- Ban / Unban
- Mute / Unmute
- Fun commands
- Modular command loader

## Environment Variables

BOT_TOKEN=your_telegram_bot_token

BOT_NAME=DEMON-TG-BOT

AUTO_REPLY=true

OWNER_ID=

## Local Run

npm install

npm start

## Render

Build Command:

npm install

Start Command:

npm start
